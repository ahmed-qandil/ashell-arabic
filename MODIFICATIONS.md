# Modifications vs upstream aShell v0.31 (sunilpaulmathew/aShell, GPLv3)

1. Full Arabic localization: `app/src/main/res/values-ar/strings.xml` now translates every translatable string (upstream Arabic covered only ~58 of ~150). App name stays English "aShell" (upstream marks it translatable=false).
2. Hardcoded English UI strings moved to string resources and translated: "Copied to clipboard" toast/clip label (Utils), "Bookmark command" and bookmark-state TalkBack labels (aShellFragment), "Expand"/"Collapse" TalkBack labels (WelcomeAdapter). New string keys: cd_bookmark_add, cd_bookmark_remove, cd_expand, cd_collapse.
3. Accessibility: contentDescription added to the icon-only settings button (activity_ashell). Other decorative icons were already marked not-important upstream; remaining controls are text buttons.
4. Settings trimmed (user rule: remove About/developer/links/useless settings): removed the app-version/copyright row, "Learn Shizuku" link, "Translations" POEditor link, "Privacy policy" entry, "Contact developer" mailto, and the now-empty "Miscellaneous" header. Remaining settings: theme, amoled toggle, language, extras, examples.
5. No update checker exists upstream - nothing update-related to strip.
6. No default of any user-toggleable setting changed (standing rule).
7. Version set to v0.31-ar1 (versionCode 32). Same package name: uninstall the original aShell before installing this one.
8. Removed after user review ("completely clean"): the version/copyright settings row, the GitLab/POEditor contribution sentence in the welcome disclaimer, and the "Learn Shizuku" link button in the Shizuku-not-found dialog (the explanatory message stays).

## ar2 changes (post-review fixes, pending build)

9. Locales stripped (standing rule: Arabic + English only): deleted all 26 upstream `values-*` locale folders except `values` (default English) and `values-ar`. The in-app Language setting now offers only "System default", "العربية", "English (US)" - previously 28 entries pointing at languages that no longer exist in the APK. Also shrinks the APK.
10. Learn-Shizuku removed completely (standing rule: when a removed entry points at a screen, remove the screen too): the Shizuku-not-available dialog got its own layout (`layout_dialog_shizuku_unavailable.xml`) with no action button instead of hiding the shared button at runtime; deleted the now-orphaned `ic_learn`/`ic_privacy`/`ic_email`/`ic_translate` drawables and their color mappings in SettingsEntry. Also deleted the dead privacy-policy screen left over from the ar1 removal: `PolicyDialog.java`, `PolicyAdapter.java`, `layout_privacy_policy.xml`, `Settings.getPolicyData()` (hardcoded English policy paragraphs) and the `copyright_text` string. The functional "Open Shizuku" dialog (AccessDeniedDialog) is untouched and still opens Shizuku.
11. English leftovers in the visible UI fixed: the main-screen History/Bookmarks/Clear/Search/Send/scroll buttons were icon-only with no labels, so screen readers announced their raw view IDs in English ("history", "bookmarks"). Added Arabic contentDescriptions to all of them plus Back/Sort (applications list), Back (file explorer), Back/Stop (logcat), a hint on the output search field, and replaced the hardcoded English "to Top"/"to Bottom" click labels in aShellFragment with string resources. New keys: cd_back, cd_sort, cd_stop, cd_search, cd_search_hint, cd_send_command, cd_scroll_top, cd_scroll_bottom. Decorative images (welcome arrow, dialog launcher icons) marked not important for accessibility.
